## 這本書是什麼

《統治地球計劃書》= **原始宣言**（DoneOnEarth 原 README）＋ **兩份研究報告**（2026-10-10 產出）合冊而成。

- 宣言回答「要做什麼」。
- 報告回答「這套想法在既有學術裡叫什麼、數字是多少、能不能被量測與證偽」。

合起來，它從一句話的口號，變成一條**可以覆核、可以實驗、可以否證**的路線。

**最短路徑**：讀每一份報告開頭的「判決」段。兩份報告都把結論寫在最前面，後面才是推導。

## 編纂原則

1. **原文照登**：第一章為原 README 全文，只加標題與目錄，不改一字。原文為粵語口語，保留原樣。
2. **報告成章**：兩份報告從單檔 HTML 轉為 Markdown，內容不刪節；表格、數字、文獻原樣保留。
3. **只引用、不代言**：封面只引用各部重點，完整內容一律指向章節，避免兩處版本不一致。
4. **可覆核**：報告中的研究數據皆列出來源，數字可自行複算。
